# Acceptance criteria

## Phone — 384 × 848 and 390 × 844

- Notes workspace does not increase document height beyond the viewport.
- Header, tabs, full Note paper, reaction footer and flip position remain visible.
- Vertical swipe changes the Note instead of scrolling the page.
- Companion panel fills the safe viewport.
- Chat composer remains visible and editable above the software keyboard/safe area.
- Bottom navigation is hidden while companion chat is open.
- No visual scrollbar track appears in the chat or Notes workspace.

## Short phone — 360 × 640

- Note paper shrinks without losing the reaction footer.
- Companion header and composer remain reachable.

## Tablet and desktop

- Companion panel remains bounded inside the viewport.
- Only chat history scrolls when necessary.
- Main application geometry remains unchanged outside the open chat.

## Intelligence regression

Question:

> Do you have recommendations for books I can read on gambling?

The answer must address gambling-related reading recommendations or ask one relevant narrowing question. It must not request a link or file unless the user asks for source handling.
