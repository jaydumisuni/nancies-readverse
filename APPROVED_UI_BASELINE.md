# Nancy’s ReadVerse — Approved UI Baseline

This branch recreates the locked approved interface from the visual references and the recovered `nancys-readverse-approved-ui-locked.html` specification.

The UI is handled in two verification passes with ten checkpoints:

1. Nancy’s / READVERSE branding
2. Desktop sidebar and search
3. Hero greeting and companion portrait
4. Companion card and quick actions
5. Continue Reading shelf
6. Feature and mood sections
7. Floating companion and chat panel
8. Settings navigation and companion grid
9. Reader, fullscreen, notes and highlights
10. Mobile header and bottom navigation

Backend work must connect to these surfaces without redesigning them.
