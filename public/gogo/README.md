# Gogo asset slots

Place only artwork that you own or have permission to use in this directory.

Planned filenames:

- `gogo-hero.webp` — mature black-theme hero artwork
- `gogo-idle-reading.webp`
- `gogo-wave.webp`
- `gogo-pointing.webp`
- `gogo-searching.webp`
- `gogo-found-book.webp`
- `gogo-playful-smirk.webp`
- `gogo-concerned.webp`
- `gogo-celebrating.webp`
- `gogo-sleepy.webp`
- `gogo-spoiler-block.webp`

Recommended export rules:

- WebP with transparent background
- consistent character scale and anchor point
- no text inside the image
- mobile-safe dimensions
- mature adult presentation

Until approved assets are added, the frontend displays a styled `G` placeholder.
